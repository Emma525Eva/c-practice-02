# 2.6  程序

### 1.程序的两种存在形式

1.源码形式：由编程语言（如C语言）编写的文本文件，具备人类可读性，无法直接交由CPU执行。

2.二进制可执行文件形式：源码经编译、链接转换得到，由机器指令构成，可被计算机直接执行。

> 对比区分：脚本属于文本命令文件，无需编译链接，可由解释器（shell等)直接解释执行；编译型程序必须经过编译链接生成二进制机器码。

### 2.过滤器（filter）

过滤器是一类遵循固定IO模型的程序：从标准输入`stdin`读取数据，对数据进行转换处理，再将结果输出至标准输出`stdout`。

- 实例：`cat`、`greep`、`tr`、`sort`、`wc`、`sed`、`awk`。
- 设计意义：该模型适配shell管道机制，多个过滤器可以串联，实现流式数据处理。

### 3.命令行参数

C语言程序通过`main`函数接受命令行参数，标准声明为：

```c
int main(int argc,char *argv[])
```

1.`argc`：`argument count`，整型，代表命令行参数总个数。`argc`包含程序名本身，因此参数数量至少为1。

2.`argv`：`argument vector`，字符指针数组，数组内每一个指针指向一条命令行参数字符串。

- `argv[0]`:固定指向程序名称字符串；
- `argv[1]、argv[2]...`：依次为用户传入的参数；
- `argv[argc]`:NULL，作为数组结束标志。

3.运行机制：`shell`在启动程序时，解析命令行，拆分参数并组装为 `argc` 与 `argv` 传递给程序。
