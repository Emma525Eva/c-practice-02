### 1.在 C 语言中，程序启动时会收到两个重要参数：

```c
int main(int argc, char *argv[])
```

其中：

- `argc`：命令行参数的数量。
- `argv`：命令行参数组成的字符串数组。

例如执行：

```
./myls -al /home
```

可以理解为：

| 变量      | 内容     |
| --------- | -------- |
| `argc`    | 3        |
| `argv[0]` | `./myls` |
| `argv[1]` | `-al`    |
| `argv[2]` | `/home`  |

### 2.`getopt()` 是 Linux C 语言编程中非常重要的一个函数，主要用于解析命令行参数

1.`getopt()` 定义在：

```c
#include <unistd.h>
```

函数原型：

```c
int getopt(int argc, char * const argv[], const char *optstring);
```

三个参数：

| 参数        | 含义                           |
| ----------- | ------------------------------ |
| `argc`      | 命令行参数数量                 |
| `argv`      | 命令行参数数组                 |
| `optstring` | 告诉 getopt() 哪些选项是合法的 |

返回值：

- 返回当前解析到的选项字符。
- 返回 `-1`：所有选项解析完成。
- 返回 `?`：遇到未知选项，或者某些选项缺少必需参数。
- 返回 `:`：在特定配置下，表示选项缺少必需参数。

注意：`getopt()` 每次只解析一个选项。

2.假设这样写：

```c
getopt(argc, argv, "al");
```

这里的 `"al"` 表示：

- `a` 是合法选项。
- `l` 是合法选项。

因此：

```
./myls -a
./myls -l
./myls -al
./myls -la
```

这些都可以被识别。

3.假设这样写：

```c
getopt(argc, argv, "a:b");
```

含义：

- `a`：需要一个参数。
- `b`：不需要参数。

执行：

```
./program -a hello
```

此时：

```c
opt = 'a';
optarg = "hello";
```

执行：

```
./program -b
```

此时：

```c
opt = 'b';
```

这里的 `optarg` 是 `getopt()` 提供的全局变量，用于保存当前选项对应的参数。

再看一个例子：

```
./program -a hello -b
```

解析过程：

| 次数   | 返回值 | optarg    |
| ------ | ------ | --------- |
| 第一次 | `'a'`  | `"hello"` |
| 第二次 | `'b'`  | `NULL`    |
| 第三次 | `-1`   | 无        |

例如：

```c
getopt(argc, argv, ":a:b");
```

最前面的冒号有特殊作用：

当某个需要参数的选项缺少参数时，返回 `':'`，而不是 `'?'`。

4.注意，`getopt()` 默认支持短选项，不直接支持 GNU 风格的长选项。

例如：

```
./program --all
```

如果需要解析 `--all`，通常使用 `getopt_long()`。

它定义在：

```c
#include <getopt.h>
```

### 4.inode

`inode`的全称是 `Index Node`（索引节点），它是 Linux 文件系统用来记录文件元信息的数据结构，每个普通文件和目录通常都有自己的 inode。

一个 inode 主要保存以下信息：

| 信息       | 含义                                 |
| ---------- | ------------------------------------ |
| inode 编号 | 文件的唯一标识（在同一个文件系统内） |
| 文件类型   | 普通文件、目录、符号链接等           |
| 文件权限   | 读、写、执行权限                     |
| 文件大小   | 文件占用的数据长度                   |
| UID        | 文件所有者的用户 ID                  |
| GID        | 文件所属组的 ID                      |
| 硬链接数   | 有多少个目录项指向该 inode           |
| 时间信息   | 访问、内容修改、元信息修改时间       |
| 数据块位置 | 文件数据在磁盘上的位置               |

inode 通常不保存文件名，文件名保存在目录的数据中，目录负责将文件名映射到 inode 编号。

- `mtime`：文件内容最后修改时间。
- `ctime`：文件 inode 元信息最后修改时间，不是文件创建时间。

### 5.结构体指针作为函数参数

1.

定义一个结构体：

```c
typedef struct
{
    int age;
    float score;
} Student;
```

- `struct`：定义结构体。
- `typedef`：给结构体类型起一个别名。
- `Student`：结构体类型名称。
- `age`、`score`：结构体成员。

创建结构体变量：

```c
Student stu;
```

给成员赋值：

```c
stu.age = 20;
stu.score = 90.5;
```

2.结构体指针

定义：

```c
Student *p;
```

- `Student`：指向的结构体类型。
- `*`：声明指针。
- `p`：指针变量名称。

- 

让指针指向结构体变量：

```c
Student stu;
Student *p = &stu;
```

3.

 **结构体变量使用点运算符** `.`

 **结构体指针使用箭头运算符** `->`
